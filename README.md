# My Portfolio - Modern React + Vite

A stunning, modern portfolio website built with React and Vite, featuring smooth animations, glassmorphism effects, and a single-page scrolling design.

## ✨ Features

- **⚡ Vite** - Lightning-fast build tool and dev server
- **🎨 Modern Design** - Glassmorphism, gradients, and smooth animations
- **📱 Responsive** - Works seamlessly on all devices
- **🎯 Single Page** - Smooth scrolling navigation
- **🚀 Performance** - Optimized for speed and efficiency
- **🎭 Animations** - Beautiful transitions and hover effects

## 🛠️ Technologies

- React 18.2.0
- Vite 5.0.8
- Modern CSS (Glassmorphism, Gradients, Animations)
- Font Awesome Icons
- Google Fonts (Poppins)

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd MyPortfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📜 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
